Why clik-engine?

Traditional game engines aren't designed for AI-assisted development. clik-engine is built around three principles:

Everything on Canvas

Claude sees the game through screenshots. Every UI component, debug overlay, and error message renders on the Phaser canvas — no invisible DOM elements.

Structured Logging

Every system logs with [CLIK:*] prefixes. Claude filters these programmatically via preview_console_logs to understand game state without screenshots.

Declarative Config

A single createGame() call with a flat config object defines the entire game. Claude reads one file and understands the full architecture.

Quick Start

Create a new game

npx create-clik-game my-game
npx create-clik-game my-game --template=platformer
npx create-clik-game my-game --template=puzzle

Run it

cd my-game
npm install
npm run dev

Game config

import { createGame, ScalePreset } from 'clik-engine';

createGame({
  name: 'my-game',
  scale: ScalePreset.AUTO,
  physics: 'arcade',
  debug: import.meta.env.DEV,
  devStartScene: 'game',
  scenes: [
    { key: 'game', class: GameScene, default: true },
  ],
  input: {
    actions: {
      move_left:  { keys: ['LEFT', 'A'], touch: 'swipe_left' },
      jump:       { keys: ['SPACE'], touch: 'tap', gamepad: '0' },
    },
  },
  save: { slots: 3, version: 1 },
});

Scene pattern

import { BaseScene } from 'clik-engine';

export class GameScene extends BaseScene {
  create(): void {
    super.create(); // Required — wires input, audio, save, director

    this.inspectState('game', () => ({
      score: this.score,  // Visible in debug overlay
    }));
  }

  update(time: number, delta: number): void {
    super.update(time, delta); // Required — polls input

    if (this.actions.justPressed('jump')) { /* ... */ }
  }
}

Engine Systems

25 system directories, 111 build modules covering everything you need for 2D game development.

Scenes

BaseScene, SceneDirector (7 transitions), SceneStack (push/pop menus), SceneUtils (hitStop, slowMotion, countdown), ScreenTransition (fade, iris, pixelate)

Input

InputManager (keyboard/touch/gamepad), ActionMap (rebinding), GestureDetector (tap, swipe, pinch), VirtualControls (floating joystick), ComboDetector, InputRecorder

UI (22 components)

Button, Label, Panel, Dialog, ProgressBar, Slider, Toggle, Toast, TextInput, ScrollContainer, GridLayout, TabBar, ListView, NumberInput, ConfirmDialog, Tooltip, Notification, FocusManager, Anchor, UIAnimator, Theme

Entity/Component

Entity, Component, EntityRegistry, EntityFactory (prefabs). 12 built-in components: Health, Movement, Timer, Collectible, Spawner, DragDrop, Follower, Lifetime, Oscillator, FlashOnHit, Patrol, Interactable

Physics

PhysicsHelper (full Arcade), MatterHelper, Raycast (line-of-sight, area queries), MovingPlatform, PhysicsPool (recycling), CollisionGroups (bitfield categories)

Animation

AnimationHelper (declarative, auto-detect from atlas), SpriteAnimator, AnimationStateController (FSM integration), AnimationEventSystem (frame callbacks for hitboxes, SFX)

Camera

CameraManager (follow, deadzone, zoom, pan, shake presets, flash, fade, path), MultiCamera (2/4-player split screen, minimap, picture-in-picture)

Networking

NetworkManager (WebSocket, auto-reconnect), Room (player tracking, ready state), StateSync (interpolation, prediction), Lobby (quick match). Plus clik-server for hosting.

Audio

AudioManager with music crossfade, per-channel muting, loop count, auto-unlock on first interaction.

Tilemap

TilemapManager for Tiled JSON maps — layers, collision, spawn points, parallax scroll factors, tile replacement, property queries.

FSM + Tweens

StateMachine (states, transitions, guards, history). TweenHelper (promise-based), Ease constants, presets (popIn, shake, pulse, float, bounceIn).

Effects

ShaderManager (blur, bloom, vignette, pixelate, CRT barrel). EffectPresets: dream, underwater, frozen, night vision, damage, retro.

Save + Assets

SaveManager (versioned localStorage slots, migration). AssetManifest (tiered: boot/main/deferred), Preloader with progress, ManifestValidator.

i18n + Dialogue

I18nManager (locales, dot-notation keys, interpolation). DialogueManager (branching trees, typewriter effect, choices, emotions).

Platform + A11y

PlatformManager (OS, lifecycle, safe area, fullscreen). CapacitorHelper (mobile native). A11yManager (color blind modes, font scale, reduced motion).

Debug

DebugOverlay, StateInspector, ConsoleReporter (per-channel), Profiler, SceneInspector (DOM editor), HotState (HMR), LeakDetector, VisualTest (regression).

Utilities

Vector2, Color, SeededRandom, ObjectPool, Grid2D, PriorityQueue, SpatialHash, A* pathfinding, GameTimer, Cooldown, EventBus, format helpers.

Analytics + Scaling

AnalyticsManager (events, pluggable backends, sessions). ResponsiveManager (breakpoints, DPI), Letterbox (cinematic bars).

Console Log Channels

Every engine system logs with structured prefixes for programmatic filtering:

PrefixPurpose
[CLIK:ENGINE]Engine lifecycle, config, camera, particles
[CLIK:SCENE]Scene init / create / shutdown / transitions
[CLIK:STATE]Game state changes (score, health, FSM)
[CLIK:INPUT]Actions, gestures, combos, button clicks
[CLIK:ERROR]Errors with fix suggestions
[CLIK:ASSET]Asset loading progress
[CLIK:AUDIO]Music / SFX events
[CLIK:SAVE]Save / load operations

Multiplayer

Client

import { NetworkManager, Room, Lobby } from 'clik-engine';

const network = new NetworkManager({ url: 'ws://localhost:8080' });
network.connect();

const lobby = new Lobby(network);
lobby.quickMatch('my-game');

const room = new Room(network);
room.onPlayerJoin(player => console.log(player.name + ' joined'));
room.sendAction('move', { x: 100, y: 200 });

Server

cd packages/clik-server
npm install
npm start  # WebSocket server on port 8080

Features: room creation/joining, player tracking, host migration, state synchronization, lobby with quick match.
